# 💫 Hi there, I'm Mihai! 👋

### 👨‍💻 About Me
A recent **B.Eng. graduate in Computer Science and Engineering** from the Faculty of Automatic Control and Computer Science (ACS, UPB). Driven, persistent, and highly organized, I have a strong passion for system-level development and intelligent architectures. Proficient in **Python, Java, and C/C++**, backed by a solid foundation in data structures, algorithms, and OOP.

I am eager to tackle complex challenges and contribute to impactful, data-driven, and highly optimized computing projects.

### 🌟 Featured Projects

| 🚀 Project                  | 📝 Description |
|-----------------------------|----------------|
| **🛡️ SysGuard AI (Thesis)** | A full-stack system telemetry and management platform. Integrates native Windows APIs with LSTM and Random Forest models for real-time resource forecasting, predictive hardware analysis, and automated system optimization. |
| **🧠 ML: NLP & CV**         | Dual-task PyTorch project implementing binary sentiment analysis via Bidirectional LSTMs (with BERT data augmentation) and 10-class image classification using CNN architectures and transfer learning. |
| **🔍 PEBS Memory Tracer**   | A lightweight, real-time memory access tracer for Linux. Leverages Intel PEBS and `perf_event_open` to capture hardware-level load/store events, visualized via a live Matplotlib heatmap dashboard. |
| **🔀 Ethernet Switch**      | Implemented MAC learning, VLAN (802.1Q), and Spanning Tree Protocol (STP) in a software-defined switch. |
| **🌐 Router Dataplane**     | Developed a router's dataplane in C to handle packet routing based on the routing table and ARP protocol. |
| **📚 Mini‑libc**            | A minimalist C standard library for Linux, handling strings, memory manipulation, and POSIX file I/O. |
| **💣 Embedded Minesweeper** | Designed a fully playable Minesweeper game using an Arduino, joystick, buttons, and a TFT display with real-time rendering. |
| **🪖 Tank Wars**            | Developed an interactive OpenGL game featuring deformable terrain, mobile tanks, projectile physics, and collision detection. |
